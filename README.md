# LAB404 Branding

Custom VS Code branding extension for **LAB404-DEV**.

## Installation

```bash
python3 install.py
```

## Features

- LAB404 home page (opens on startup)
- Status bar brand mark
- `LAB404: Open Home` command

## Development

Open in VS Code, press **F5** to launch Extension Development Host.
