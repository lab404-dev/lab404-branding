# 🍪 LAB404 Branding Extension

Custom VS Code branding extension for **LAB404-DEV** - bringing lab vibes, custom home page, and official cookie support directly into your workspace.

## 🚀 Installation

```bash
python3 install.py
```

## ✨ Features

- LAB404 home page (opens on startup)
- Status bar brand mark
- `LAB404: Open Home` command
- Cookie Support 🍪: Officially boosts coding efficiency by 404% when accompanied by real cookies.

## 🛠️ Development

Open in VS Code, press **F5** to launch Extension Development Host.
